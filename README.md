# China, unfolded.

一个中英双语的中国旅行规划网站，支持目的地探索、行程安排、预算估算和浏览器本地保存。

## 预览

直接用浏览器打开 index.html，或打开完整单文件版本 China-Unfolded.html。无需安装依赖或构建。

## 文件

- index.html：网站入口。
- styles.css：从原文件提取的完整样式。
- scenes.js：原网站的 SVG 风景图形。
- app.js：原网站的界面、行程及预算逻辑。
- China-Unfolded.html：用户提供的原始单文件，逐字节保留。

拆分版本保持原文件的样式、脚本内容及加载顺序。后续修改拆分版本时，请同时维护单文件版本。

## 数据和使用范围

行程和清单保存在当前浏览器的 localStorage 中，没有账号或云端同步。预算和行程是规划参考，不提供实时价格或预订服务。

本仓库仅保存网站源码，未配置自动部署或公开网站。
